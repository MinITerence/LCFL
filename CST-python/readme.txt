1、MIT-BIH Arrhythmia Database:

2、PTB-XL Dataset:
     Access the data from the PTB-XL Dataset（https://www.physionet.org/content/ptb-xl/1.0.1/）.
     Utilize the data preprocessing and network architecture instructions available at https://github.com/usc-sail/fed-multimodal?utm_source=catalyzex.com.
